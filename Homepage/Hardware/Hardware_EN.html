Reference project for Murata

Yamori – a product we built for Murata

Yamori is a reference product developed by Sentinum for Murata: an industrial-grade embedded platform based on the latest LPWAN modules—including 3D-MID antenna structures, developed in collaboration with the FAPS Chair at FAU Erlangen-Nuremberg. A concrete example of how we bring hardware from concept to market-ready product.

  • Reference Project – Developed for and with Murata
  • Embedded platform based on the latest Murata LPWAN modules
  • Energy-efficient connectivity, industrialized to production readiness
  • 3D-MID antenna structures, developed with FAU Erlangen-Nuremberg (FAPS)
