Frequently Asked Questions

The Juno IP67 TH is a rugged IoT sensor from Sentinum for temperature and relative humidity—available as a stationary sensor and as a mobile tracker with GNSS and WiFi scanning.
The TH sensor is designed for stationary monitoring (control cabinets, warehouses, HVAC). The TH tracker additionally features GNSS scanning, WiFi scanning, and BLE—ideal for cold chains and moving assets.
LoRaWAN®, mioty®, as well as NB-IoT and LTE-M (LTE-CAT-M1)—depending on the model. This allows the Juno TH to fit into local sensor networks as well as global cellular rollouts.
Via NFC – and via BLE for the tracker. Measurement and transmission frequencies, modes, and thresholds can be set via smartphone without opening the housing.
