Febris CO2 NFC and Downlink Table

Timings & Alarms Group

Name: Measurement Period
Communication Protocol: All
Description: Specifies the period during which measurements are recorded. A setting of 10 minutes means that a measurement is taken every 10 minutes.
Key (NFC Parameter): period
Module: Sentiface
Module Key: 0x1111
Group: 0x00
Property ID: 0x00
Default Value: 5
Minimum Configurable Value: 1
Maximum Configurable Value: 60
Unit: min
Read/Write: rw

Name: Regular Transmission Interval
Communication Protocol: All
Description: Number of measurements after which the sensor sends a regular uplink even without an active alarm condition.
Module: Sentiface
Module Key: 0x1111
Group: 0x00
Property ID: 0x01
Default value: 6
Minimum settable value: 1
Maximum settable value: 64
Unit: Number
Read/Write: rw

Name: Save and transmit values (Use this feature only after consultation)
Communication protocol: All
Description: Specifies whether past measurement values are additionally saved and transmitted. Available starting with minor version 1.2.

  • 0: Off
  • 1: On

Enable Measurement History

Module: Sentiface
Module Key: 0x1121
Group: 0x00
Property ID: 0x02
Default value: 0
Minimum settable value: 0
Maximum settable value: 1
Unit: –
read/write: rw

Number of stored values

Name: Number of stored values (Use this feature only after consultation)
Communication protocol: All
Description: Maximum number of past measurement values, that are transmitted during a broadcast. The actual possible number depends on the communication technology used (as of minor version 1.2).
Key (NFC parameter): pastnum
Module: Sentiface
Module key: 0x1121
Group: 0x00
Property ID: 0x02
Default value: Max (30 / 6)
Minimum adjustable value: 1
Maximum adjustable value: 30 (NB-IoT) / 6 (LoRaWAN)
Unit: –
read/write: rw

Delta Value

Name: Delta Value
Communication Protocol: All
Description: Specifies the absolute change in the CO₂ value compared to the last transmission that must occur to trigger an alarm transmission. This transmission occurs independently of the regular transmission interval.
Key (NFC Parameter): delta
Module: Sentiface
Module Key: 0x1111
Group: 0x01
Property ID: 0x00
Default value: 300
Minimum settable value: 300
Maximum settable value: 2000
Unit: ppm
read/write: rw

Name: Threshold for yellow alarm
Communication protocol: All
Description: Specifies the CO₂ threshold in ppm that must be exceeded for the sensor to switch to the yellow state (yellow LED lights up).
Key (NFC Parameter): yellow
Module: Sentiface
Module Key: 0x1111
Group: 0x01
Property ID: 0x01
Default Value: 1000
Minimum settable value: 500
Maximum settable value: 3000
Unit: ppm
Read/Write: rw

Name: Red Alarm Threshold
Communication Protocol: All
Description: Specifies the CO₂ threshold in ppm that must be exceeded for the sensor to switch to the red state (red LED lights up) .
Key (NFC parameter): red
Module: Sentiface
Module key: 0x1111
Group: 0x01
Property ID: 0x02
Default value: 2000
Minimum settable value: 500
Maximum settable value: 3000
Unit: ppm
Read/Write: rw

Name: Hysteresis
Communication Protocol: All
Description: Determines the absolute hysteresis in ppm during state transitions. If the CO₂ concentration falls below a threshold value minus the hysteresis, the system switches from a higher to a lower alarm state.
Key (NFC Parameter): hyst
Module: Sentiface
Module Key: 0x1111
Group: 0x01
Property ID: 0x03
Default value: 5
Minimum settable value: 0
Maximum adjustable value: 300
Unit: ppm
Read/Write: rw

Buzzer Settings Group

Name: Buzzer Settings
Communication Protocol: All
Description: Specifies the behavior of the buzzer.

  • 0: Buzzer off
  • 1: Buzzer sounds when alarm levels change beyond the defined thresholds
  • 2: Continuous signaling in the event of an alarm. In yellow or red status, the buzzer signals the status with every measurement.
  • 3: The buzzer signals only the transition to the red state.
  • 4: The buzzer sounds continuously as long as the red status is active.

Key (NFC parameter): buzz
Module: Sentiface
Module Key: 0x1111
Group: 0x02
Property ID: 0x00
Default Value: 1
Minimum Configurable Value: 0
Maximum Configurable Value: 4
Read/ Write: rw
