4. SENTIFACE: Opening Detection Group 0x02

Resources Resource ID Description Key (NFC/BLE) Min Max Factory Setting Unit Module Key
Opening Cooldown 0x00 Specifies a time period during which, after an opening event is triggered, another opening event cannot be triggered again (de-bounces the openings). The last counted opening serves as the reference value. acool 0 600 0 sec 1111
Opening time AlarmM 0x01 Specifies how long the lid must remain open before an alarm is triggered. oaaf 0 2880 0 sec 1111
Opening Mode 0x02 Describes the direction the sensor faces when it is closed and the angles defined for opening detection. “Face up” describes the state when the sensor is lying on the table and facing upward toward the ceiling.

Settings 0–7 with accelerometer, 8–9 with Hall sensor:

0: Off
1: Ultra Low Power. Fixed threshold of 50°. Closed when facing down (Face Down).
2: Ultra Low Power. Fixed threshold of 50°. Closed when facing up (Face Up).
3: Ultra Low Power. Fixed threshold of 50°. Closed when facing to the side.
4: Advanced tilt sensing. Adjustable threshold. Closed when facing down (Face Down).
5: Advanced tilt sensing. Adjustable threshold. Closed when facing up (Face Up).
6: Advanced tilt sampling. Adjustable threshold. Closed when facing sideways.
7: Advanced tilt sampling. Adjustable threshold. Automatic calibration of the closed orientation.
8: Container is closed when a magnet is present.
9: Container is open when magnet is in contact. 		opmo 0 8 1 1111

5. SENTIFACE: Advanced Tilt Settings Group 0x03

Resources Resource ID Description Key (NFC/BLE) Min Max Factory Setting Unit Module Key
Sampling Period 0x00 Specifies how often the accelerometer measures the angle. The higher the frequency, the higher the power consumption. tspe 2 600 2 s 1111
Trigger Level 0x01 Specifies the angle at which an opening is detected or an alarm is triggered. ttle 5 180 20 ° 1111
Trigger Hysteresis 0x02 Hysteresis value for the opening angle. tthy 1 90 4 ° 1111
