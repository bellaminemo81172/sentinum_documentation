1. General Description

The Juno IP67 TH is a versatile temperature and relative humidity sensor that uses mioty®, LoRaWAN®, or cellular technologies such as NB-IoT for reliable and energy-efficient data transmission. Thanks to its robust design and IP67 rating , it is ideally suited for use in demanding environments and withstands dust, water, and high pressures.

2. Features

  • LoRaWAN®, mioty®, or NB-IoT communication
  • IP67, −25°C to 85°C, IK07
  • Tilt and flap-opening detection
  • Advanced tilt detection with 1° resolution and threshold values
  • Magnetic switch
  • Can be activated with a magnet (no smartphone required) or via NFC
  • Configurable via downlinks or NFC
  • Adjustable threshold values
  • Replaceable AA batteries (LiSOCl₂, see Saft LS14500)
  • Audible alarm

3. Example Applications

  • Cold chain monitoring
  • Temperature monitoring in building management or smart city applications
  • Manhole cover monitoring
  • Flap opening detection
