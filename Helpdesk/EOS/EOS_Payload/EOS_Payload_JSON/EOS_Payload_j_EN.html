Cellular JSON Payload

JSON Key Type Source Resource Unit / Scale Description
variant Integer EOS_VARIANT_CODE() Raw module code EOS firmware/module variant
up_cnt Integer Encoder-local counter Is incremented for each encoded cellular telemetry message Uplink counter
alarm Integer is_alarm Raw bit field Alarm Flags
internal_temperature Integer temp degC Internal temperature
capacity Integer batt % Battery capacity
battery_voltage Float vbat mV Battery voltage; the encoder multiplies volts by 1000
radar_status Integer r_ok 0 or 1 Radar detection status
radar_peaks Integer r_peaks Number Detected radar peaks
radar_rd_1 Float rd0 m Distance to Radar Peak 1
radar_ra_1 Integer ra0 dBsm Radar Peak 1 RCS/Amplitude
radar_rd_2 Float rd1 m Distance to Radar Peak 2
radar_ra_2 Integer ra1 dBsm Radar Peak 2 RCS/Amplitude
radar_rd_3 Float rd2 m Distance Radar Peak 3
radar_ra_3 Integer ra2 dBsm Radar Peak 3 RCS/Amplitude
orientation Integer ornt Enum Orientation
tilt_angle Integer angl deg Tilt angle
