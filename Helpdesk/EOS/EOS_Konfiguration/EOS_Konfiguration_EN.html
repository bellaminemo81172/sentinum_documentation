Resource ID Description Key Min Max Factory setting Unit Module Key

Delta Alarm 0x01 Change in the measured distance/level since the last transmission. delta 0.03 10.0 3.0 m XXX1
Regular transmission interval 0x02 Number of measurements until regular transmission. every 1 24 1 Measurements XXX1
Full Threshold 0x04 Lower distance threshold for full/minimum detection. full 0.0 10.0 0.2 m XXX1

Active Radar Alarm 0x07 Bit field for activating radar alarms. aact 0 7 0 Bit field XXX1

1.1 Alarm Mode aact - Group 0x00

Bit 0 activates the delta alarm, Bit 1 activates the min/full alarm, and Bit 2 activates the max/empty alarm.

aact value Delta Alarm Min/Full Alarm Max/Empty Alarm Meaning
0 Off Off Off No radar level alarm
1 on off off Delta alarm only
2 off on off Min/Full Alarm Only
3 on on off Delta and Min/Full Alarms
4 off off on Max/Empty alarm only
5 on off on Delta and Max/Empty Alarms
6 off on on Min/Full and Max/Empty Alarms
7 on on on Delta, Min/Full, and Max/Empty Alarms

3. LED - Group 0x03

Resource ID Description Key Min Max Factory setting Unit Module Key
LED MODE 0x00 Sets the scope of the LED indicators: 0 = off, 1 = all indicators, 2 = mandatory indicators only. led 0 2 2 enum XXX1

3.1 LED Indicators - Group 0x03

Mandatory indicators: Power on, Power off, BLE Advertising, BLE Connected, and Alarm. Optional indicators: Network Joined, Measurement Flash, and Always-on Status Color.

Value Mode Required fields Optional fields
0 Off Disabled Disabled
1 All Enabled Enabled
2 Required only Enabled Disabled

7. Sample Commands

The following examples show typical configuration values. 

Set the measurement interval to 15 minutes

Key: period
Value: 15

Set the delta alarm to 1 meter

Key: delta
Value: 1.0

Fully enable LED indicators

Key: led
Value: 1

Set the radar filter type to moving average

Key: rsft
Value: 2

Configure opening detection to "Face Up"

Key: opmo
Value: 2

Trigger manual measurement

Key: measure
Value: 0x0001
Note

The parameters actually available depend on the firmware version, product variant, and module key.
