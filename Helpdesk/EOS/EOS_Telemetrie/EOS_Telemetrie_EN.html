Telemetry Resources - Group 0x01

Key ID Type Factory setting Min Max Unit Description
is_alarm 17 integer 0 0 255 bit field Alarm flags and user action bits
r_ok 18 integer 0 0 1 bool Radar detection status
r_peaks 19 integer 0 0 3 Number Number of detected radar peaks
rd0 20 float 0.0 0.0 5.0 m Distance to Radar Peak 1
ra0 21 integer 0 -100 100 dBsm Radar Peak 1 RCS/Amplitude
rd1 22 float 0.0 0.0 5.0 m Distance to Radar Peak 2
ra1 23 integer 0 -100 100 dBsm Radar Peak 2 RCS/Amplitude
rd2 24 float 0.0 0.0 5.0 m Distance from Radar Peak 3
ra2 25 integer 0 -100 100 dBsm Radar Peak 3 RCS/Amplitude
temp 26 integer 0 -40 125 degC Internal temperature
batt 27 integer 0 0 100 % Battery capacity
vbat 28 float 0.0 0.0 10.0 V Battery voltage
ornt 29 integer 0 0 4 enum Orientation; currently used: 0 = vertical, 1 = face up, 2 = face down
eng 30 integer 0 0 180 deg Angle of inclination

Alarm flags in is_alarm

Bit(s) Mask Meaning
0 0x01 Opening alarm
1 0x02 Vandalism alarm
2 0x04 Reserved / currently unused
3 0x08 Radar Delta Alarm
4 0x10 Radar Min/Full Alarm
5 0x20 Radar Max/Empty Alarm
6..7 0xC0 User action: 0 = none, 1 = activation, 2 = configuration, 3 = manual triggering
Note

The telemetry resources are updated after every successful measurement and can be read via NFC, BLE, or downlink protocols .
