1. Module Overview

Module Module Key Group Group ID Description
Sentiface 0x1XXX Timings 0x00 Defines parameters for measurements and transmission behavior
Sentiface 0x1XXX Alarm Settings 0x01 Defines measurement thresholds for triggering the CO₂ sensor alarm
Sentiface 0x1XXX Buzzer 0x02 Defines the buzzer behavior
Sentiface 0x1XXX LED 0x04 Turns LEDs on or off
Sentiface 0x1XXX Humidity alarm 0x05 Defines measurement thresholds for triggering the humidity sensor alarm

Tables for cross-product modules (Senticom / Sentivisor) can be found in the generic NFC and downlink documentation .

For more information on configuring sensor communication, depending on the version, see the respective generic LoRaWAN® documentation or Mioty® documentation .

3rd Group: Alarm Settings 0x01

Property Property ID Description Key (NFC/BLE) Min Max Default Unit Module Key
Delta Threshold 0x00 Specifies the absolute change in the CO₂ value compared to the last transmission that must occur to trigger an ALARM transmission. This transmission is performed independently of the normal transmission interval. delta 300 2000 300 ppm 1111
Yellow Threshold 0x01 Specifies the CO₂ threshold that must be exceeded for the sensor to switch to the yellow state (yellow LED lights up). yellow 500 3000 1000 ppm 1111
Red threshold 0x02 Specifies the CO₂ threshold that must be exceeded for the sensor to switch to the red state (red LED lights up). red 500 3000 2000 ppm 1111
Level Hysteresis 0x03 Determines the absolute hysteresis for state changes. If the CO₂ concentration falls below a threshold minus the hysteresis, the system switches from a higher to a lower alarm state. hyst 0 300 100 ppm 1111

4th Buzzer Group0x02

Property Property ID Description Key (NFC/BLE) Min Max Default Unit Module Key
Buzzer Setting 0x00 Defines the buzzer’s behavior.
0: Buzzer off
1: Buzzer sounds when the alarm level changes above the specified thresholds (red, yellow, green)
2: Always on in the event of an alarm (if the sensor remains in the yellow or red state, the buzzer signals the state with every measurement)
3: Buzzer sounds only when the status changes to red
4: Buzzer sounds continuously while the red status persists
5: Buzzer sounds continuously when the status is not in the green range and a level change occurs above the defined thresholds 		buzz 0 5 1 - 1111

5th LED Group 0x04

Property Property ID Description Key (NFC/BLE) Min Max Default Unit Module Key
LED Setting 0x00 Defines the behavior of the LEDs:
0: All LEDs off
1: All LEDs on 		leds 0 1 0 - 1111

Group 6: Humidity Alarm 0x05

Property Property ID Description Key (NFC/BLE) Min Max Default Unit Module Key
Humidity Alarm 0x00 Enables the humidity alarm when the status is 1, and disables it when the status is 0. ads 0 1 0 - 1111
Delta Threshold 0x01 Specifies the absolute value by which the humidity must change compared to the last transmission in order to trigger an ALARM transmission. This transmission is performed independently of the normal transmission interval. hdt 5 100 20 %RH 1111
Yellow threshold 0x02 Specifies the humidity threshold that must be exceeded for the sensor to switch to the yellow state (yellow LED lights up). hyt 10 100 60 %RH 1111
Red threshold 0x03 Specifies the humidity threshold that must be exceeded for the sensor to switch to the red state (red LED lights up). hrt 10 100 80 %RH 1111
Level Hysteresis 0x04 Determines the absolute hysteresis for state changes. If the humidity falls below a threshold minus the hysteresis, the system switches from a higher to a lower alarm state. hlh 0 300 5 %RH 1111
