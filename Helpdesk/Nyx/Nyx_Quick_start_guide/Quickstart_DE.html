1. Produktübersicht

Der solarbetriebene, drahtlose IoT-Sensor NYX ist eine innovative Lösung zur Überwachung von Raumklimaparametern. Solarbetrieben und nur 8 mm dünn, bietet er ein wartungsfreies und attraktives Design für Innenräume.

Der Sensor erfasst Temperatur, relative Luftfeuchtigkeit und Umgebungslicht. Der Sensor ist mit LoRaWAN® und mioty® in verschiedenen Sensorkonfigurationen erhältlich.

Bitte befolgen Sie die Warnhinweise und Anweisungen in der Bedienungsanleitung, um die Sicherheit für sich selbst, Ihre Umgebung und den Sensor zu gewährleisten.

2. Montage und Installation

Befestigen Sie die Wandhalterung an einer Innenwand in einer Höhe von 1,50 m bis 1,80 m an einem Ort mit mindestens 400 Lux pro Tag. Achten Sie auf einen Mindestabstand von 20 cm zu Personen und einen Betrieb unterhalb von 2 000 m über dem Meeresspiegel.

3. Inbetriebnahme und NFC-Konfiguration

Der Sensor wird bereits eingeschaltet ausgeliefert. Er wird über eine NFC-App aktiviert. Hierfür ist ein Smartphone erforderlich. Die App kann aus den jeweiligen App-Stores heruntergeladen werden . Suchen Sie einfach nach „Sentinum LinQs“ und laden Sie die LinQs-App herunter.

Suchen Sie zunächst das Tag auf dem Sensor und anschließend das NFC-Lesegerät auf Ihrem Gerät. Die genaue Position des NFC-Tags auf dem Sensor ist in der folgenden Abbildung dargestellt.

4. Payload-Decoder – NYX-Serie

function decodeUplink(input) {
    var decoded = {};
    var bytes = input.bytes;
    
if (input.fPort == 1) {

        decoded.base_id = bytes[0] >> 4;
        decoded.major_version = bytes[0] & 0x0F;
        decoded.minor_version = bytes[1] >> 4;
        decoded.product_version = bytes[1] & 0x0F;
        
decoded.up_cnt = bytes[2];
        decoded.battery_voltage = ((bytes[3] << 8) | bytes[4]) / 1000.0;
        decoded.internal_temperature =
            ((bytes[5] << 8) | bytes[6]) / 10 - 100;
    
}
    
return {
        data: decoded,
        warnings: [],
        errors: []
    };
}
