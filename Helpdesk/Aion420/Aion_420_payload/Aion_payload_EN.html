1. Payload Overview

Property Value
Payload Type LPWAN Binary Payload for Telemetry Data
Total Size 19 bytes
Byte Order Big-endian for multi-byte values
Compilation Condition The encoder is used when CONFIG_SENTOS_HAS_NRF_CLOUD_SERVICE is disabled
Structure 3-byte Sentigram telemetry header, followed by Aion telemetry fields

2. LPWAN Binary Payload Structure

Byte Offset Size Field Type Encoding / Scaling Description
0 1 variant_msb uint8 High byte of AION_VARIANT_CODE() Bits for module base and major version
1 1 variant_lsb uint8 Low byte of AION_VARIANT_CODE() Minor version and subtype bits
2 1 uplink_counter uint8 Incremented per message Uplink counter
3 1 id uint8 Lowest byte of the telemetry ID User-defined device ID
4 1 internal_temperature uint8 Raw value = °C + 128 Internal temperature
5 1 alarm uint8 Raw alarm bitmask Channel-specific alarm status
6 1 status uint8 Packed status bitmask Channel-specific status
7–8 2 current_ch1_mA int16 mA × 100 Raw current, channel 1
9–10 2 current_ch2_mA int16 mA × 100 Raw current, channel 2
11–12 2 lower_ch1 int16 Engineering value × 100 Lower limit for Channel 1 at 4 mA
13–14 2 lower_ch2 int16 Engineering value × 100 Lower limit for Channel 2 at 4 mA
15–16 2 upper_ch1 int16 Engineering value × 100 Upper limit for channel 1 at 20 mA
17–18 2 upper_ch2 int16 Engineering value × 100 Upper limit for Channel 2 at 20 mA

3. Field Description

  • Total length of payload data: 19 bytes
  • All multi-byte integer values are transmitted in Big-Endian format.
  • The first 3 bytes form the Sentigram telemetry header.
  • The following bytes contain the AION-specific telemetry data.
  • Current values are encoded with a factor of 100.
  • Engineering limit values are also transmitted multiplied by a factor of 100.
