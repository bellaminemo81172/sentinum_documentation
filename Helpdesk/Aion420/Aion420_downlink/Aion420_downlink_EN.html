1. Overview

The AION 4–20 mA adapter provides various resources for configuration, parameterization, and diagnostics. The resources are organized into groups and can be configured via downlinks.

Resource Group Group ID Description
AION Timing 0x00 Measurement interval and keep-alive uplink interval
AION Configuration 0x01 Scaling, alarm values, delta thresholds, and device ID
AION Telemetry 0x02 Read-only measurement values after a measurement
AION Trigger 0x01 Manual measurement trigger

Timing Parameters (Group 0x00)

Parameter ID Description
Measurement period 0x00 Regular measurement period in minutes (1 to 660 minutes)
Regular transmission interval 0x01 Keep-Alive Uplink Interval in number of measurements (1 to 24)
  • The measurement period defines the regular measurement interval.
  • The transmission interval determines after how many measurements an uplink is sent.

2. Configuration Parameters (Group 0x01)

Parameter ID Description
CHANNEL 1 Upper Range 0x00 Engineering value at 20 mA (upper1)
CHANNEL 2 Upper Range 0x01 Engineering value at 20 mA (upper2)
CHANNEL 1 Alarm Threshold 0x02 Alarm Threshold Channel 1 (thr1)
CHANNEL 2 Alarm Threshold 0x03 Alarm threshold for Channel 2 (thr2)
CHANNEL 1 ALARM HYSTERESIS 0x04 Alarm hysteresis for Channel 1 (hyst1)
CHANNEL 2 ALARM HYSTERESIS 0x05 Alarm Hysteresis Channel 2 (hyst2)
DEVICE/CONFIG ID 0x06 User-defined device ID
CHANNEL 1 Lower Range 0x07 Engineering value at 4 mA (lower1)
CHANNEL 2 Lower Range 0x08 Engineering Value at 4 mA (lower2)
CHANNEL 1 Delta 0x09 Channel 1 Delta Threshold (delta1)
Channel 2 Delta 0x0A Channel 2 Delta Threshold (delta2)

Configuration Options

The following compile-time options control the activation of certain functions within the firmware.

Configuration Symbol Type Default Description
CONFIG_SENTOS_MODULE_AION bool n Enables the Aion module.
  • CONFIG_SENTOS_MODULE_AION=y enables the AION-specific functions at runtime.
  • The factory setting n means that the module is disabled by default.
  • This option is evaluated at build time and is not a downlink parameter.

3. Scaling of 4–20 mA

The sensor current is scaled to an engineering value.

Input Current Meaning
4 mA corresponds to lowerN
20 mA corresponds to upperN

Calculation formula:

scaled = lower + ((current_mA - 4.0) / 16.0) * (upper - lower)

  • lowerN defines the measured value at 4 mA.
  • upperN defines the measured value at 20 mA.
  • Intermediate values are linearly interpolated.

4. Alarm Behavior

Setting Behavior
thrN = 0 Alarm evaluation disabled
thrN ≠ 0 Alarm triggered when value ≥ threshold
hystN Alarm is cleared only when value < (thrN - hystN)
  • Hysteresis prevents the alarm from turning on and off frequently.
  • The alarm is not reset until the measured value falls sufficiently below the threshold.

5. Delta Behavior

Setting Behavior
deltaN = 0 Delta-based transmission disabled
deltaN > 0 Uplink is triggered as soon as the value has changed by at least deltaN
  • Delta transmission allows additional uplinks to be generated when relevant measurement values change.
  • This ensures that critical changes are transmitted more quickly.

6. Manual Measurement Trigger (Trigger Group 0x01)

Parameter ID Description
Trigger Measurement 0x01 Triggers an unscheduled measurement

The trigger expects a 2-byte big-endian command value.

Value Function
0x0001 Perform measurement and send uplink
Any other value Local user-triggered measurement without forced uplink
  • The trigger function is intended exclusively for manually triggering measurements.
  • A 2-byte big-endian value must be transmitted for the trigger.
