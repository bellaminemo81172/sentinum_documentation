1. Payload Overview

Property Value
Payload Type LPWAN Binary Payload
Total Size 8 to 72 bytes
Data Source IO-Link Process Data
Supported Sensors IO-Link Devices According to IEC 61131-9
Byte Order Big Endian
Variable Fields PDIN and PDOUT

2. Payload Structure

Byte Offset Size Field Type Encoding / Scaling Description
0 1 variant_msb uint8 AION_VARIANT_CODE() Module base and major version
1 1 variant_lsb uint8 AION_VARIANT_CODE() Minor version and subtype
2 1 uplink_counter uint8 Incremented per telegram Message counter
3–4 2 vendor_id uint16 IO-Link Vendor ID Sensor manufacturer ID
5-7 3 device_id uint24 IO-Link Device ID Device ID of the sensor
8-(7+n) 0...32 pdin Byte Array Raw Input Data IO-Link Process Data Input
(8+n)-(7+n+m) 0...32 pdout Byte Array Raw Output Data IO-Link Process Data Output

3. Field Description

  • variant_msb / variant_lsb identify the device type and firmware version.
  • uplink_counter enables tracking of received telegrams.
  • vendor_id identifies the IO-Link manufacturer based on the official vendor ID.
  • device_id uniquely identifies the connected sensor type.
  • pdin contains the process data provided by the sensor.
  • pdout contains optional output data from the IO-Link device.

4. IO-Link Process Data

The fields PDIN and PDOUT have a variable length. The exact interpretation depends on the IO-Link sensor used and the associated IODD file.

Field Max. Size Description
PDIN 32 bytes Process data from the sensor to the AION LIO
PDOUT 32 bytes Process data from the AION LIO to the sensor

5. Payload Example

Payload Hex
14 01 05 01 F4 00 01 23 00 82 00 3C

Field Value
Vendor ID 500
Device ID 291
PDIN 00 82 00 3C

6. Technical Notes

  • The payload length depends on the length of the IO-Link process data.
  • The Vendor ID and Device ID are used for automatic sensor detection.
  • The process data is interpreted using the corresponding IODD file of the connected IO-Link device. This allows raw data to be automatically converted into meaningful measured values, units, states, and diagnostic information.
