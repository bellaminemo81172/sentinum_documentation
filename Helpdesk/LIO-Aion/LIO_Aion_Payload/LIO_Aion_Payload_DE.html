1. Payload Übersicht

Eigenschaft Wert
Payload Typ LPWAN Binary Payload
Gesamtgröße 8 bis 72 Byte
Datenquelle IO-Link Prozessdaten
Unterstützte Sensoren IO-Link Geräte nach IEC 61131-9
Byte-Reihenfolge Big Endian
Variable Felder PDIN und PDOUT

2. Payload Aufbau

Byte Offset Größe Feld Typ Kodierung / Skalierung Beschreibung
0 1 variant_msb uint8 AION_VARIANT_CODE() Modulbasis und Major-Version
1 1 variant_lsb uint8 AION_VARIANT_CODE() Minor-Version und Subtype
2 1 uplink_counter uint8 Inkrementiert pro Telegramm Nachrichtenzähler
3-4 2 vendor_id uint16 IO-Link Vendor ID Hersteller-ID des Sensors
5-7 3 device_id uint24 IO-Link Device ID Geräte-ID des Sensors
8-(7+n) 0...32 pdin Byte Array Raw Input Data IO-Link Prozessdaten Eingang
(8+n)-(7+n+m) 0...32 pdout Byte Array Raw Output Data IO-Link Prozessdaten Ausgang

3. Feldbeschreibung

  • variant_msb / variant_lsb identifizieren Gerätetyp und Firmwareversion.
  • uplink_counter ermöglicht die Nachverfolgung empfangener Telegramme.
  • vendor_id identifiziert den IO-Link-Hersteller nach offizieller Vendor-ID.
  • device_id identifiziert den angeschlossenen Sensortyp eindeutig.
  • pdin enthält die vom Sensor bereitgestellten Prozessdaten.
  • pdout enthält optionale Ausgangsdaten des IO-Link-Gerätes.

4. IO-Link Prozessdaten

Die Felder PDIN und PDOUT besitzen eine variable Länge. Die genaue Interpretation hängt vom verwendeten IO-Link Sensor sowie der zugehörigen IODD-Datei ab.

Feld Max. Größe Beschreibung
PDIN 32 Byte Prozessdaten vom Sensor zum AION LIO
PDOUT 32 Byte Prozessdaten vom AION LIO zum Sensor

5. Payload Beispiel

Payload Hex
14 01 05 01 F4 00 01 23 00 82 00 3C

Feld Wert
Vendor ID 500
Device ID 291
PDIN 00 82 00 3C

6. Technische Hinweise

  • Payloadlänge ist abhängig von der Länge der IO-Link Prozessdaten.
  • Vendor-ID und Device-ID dienen zur automatischen Sensorerkennung.
  • Die Interpretation der Prozessdaten erfolgt über die zugehörige IODD-Datei des angeschlossenen IO-Link-Geräts. Dadurch können Rohdaten automatisch in verständliche Messwerte, Einheiten, Zustände und Diagnoseinformationen umgewandelt werden.
