4. Timing Gruppe (0x00)

Ressource ID Schlüssel Min Max Default Einheit
Messperiode 0x00 period 1 660 5 Minuten
Reguläres Sendeintervall 0x01 every 1 24 1 Messungen

5. Trigger Gruppe (0x01)

Ressource ID Beschreibung Eingang
Messung auslösen 0x01 0x0001 löst eine unmittelbare Messung aus und sendet die Daten per Uplink. Jeder andere Zwei-Byte-Wert startet lediglich eine lokale Messung. 2-Byte Big-Endian

6. Technische Hinweise

  • Das Messintervall kann zwischen 1 und 660 Minuten konfiguriert werden.
  • Das Keep-Alive-Uplink-Intervall wird als Anzahl von Messungen definiert.
  • Der IO-Link Start-Up Timeout ist zwischen 1000 ms und 30000 ms konfigurierbar.
  • Die Gruppe "IO-Link Telemetrie" stellt die Geräteidentität sowie Roh-Prozessdaten bereit.
  • Die Trigger-Funktion unterstützt eine Remote-Auslösung von Messungen über einen Big-Endian-Befehlswert.
  • Alle IO-Link Prozessdaten werden vom integrierten AION LIO IO-Link Master bereitgestellt.
