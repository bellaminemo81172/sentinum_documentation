3. Default Settings / Factory Default Values

Name For Communication Protocol Description Unit Default Value
Measurement Interval All Specifies the period during which measurement values are recorded . 10 minutes means that every 10 minutes the sensor takes a measurement. min 5
Delta Value All Specifies the absolute change in the measured value compared to the last transmission that must occur for an alarm transmission to be triggered. This transmission is carried out regardless of the regular transmission interval. Always refers to the main measured value. mbar 100
Regular Transmission Interval All Number of measurements after which the sensor sends an uplink even if no alarm condition exists. Number 2
Low Temperature Warning All Threshold value in °C at which an alarm message is triggered due to a temperature that is too low. °C 4
High Temperature Warning All Threshold value in °C at which an alarm message is triggered due to a temperature that is too high (first high temperature threshold). °C 55
Critical Temperature Warning All Threshold value in °C at which an alarm is triggered due to a critical, excessively high temperature (second high-temperature threshold). °C 55
Low Pressure Warning All Threshold value in mbar at which an alarm is triggered due to pressure that is too low. mbar 8000
High Pressure Warning All Threshold value in mbar at which an alarm is triggered due to excessive pressure (first high-pressure threshold). mbar 200
Critical Pressure Warning All Threshold value in mbar at which an alarm is triggered due to critical, excessively high pressure (second high-pressure threshold). mbar 8000
