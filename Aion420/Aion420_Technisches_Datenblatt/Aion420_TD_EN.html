The AION420 is a compact IoT bridge for wirelessly connecting industrial 4–20 mA sensors to LoRaWAN® and mioty® networks. The device acquires analog process values and transmits the measured values energy-efficiently to existing IoT platforms without requiring additional cabling or local infrastructure.

Since the AION420 is part of the 4–20 mA current loop, the device is powered by an external power supply. This makes it particularly suitable for applications with an existing power supply and provides a reliable connection of existing measurement points to modern IoT infrastructures.

For easy integration into various systems, the AION420 is available both as a terminated version for direct connection to a sensor and as a loop-through version for integration into existing sensor cabling .

This allows existing 4–20 mA sensors to be digitized quickly and cost-effectively .

Typical applications include the monitoring of levels, pressures, flow rates, temperatures, and other process variables in industrial, energy, water, and environmental applications.

6.4. Connection Schematic and Pin Assignment (Supply Side) for the Looped Version

In addition to providing power, the looped-through version of the AION420 also allows the 4–20 mA signal to pass through. This enables the AION420 to be integrated into existing measurement circuits without interfering with the existing signal processing.

The measurement signal is acquired by the device and simultaneously forwarded to downstream systems, such as PLCs, data loggers, or process control systems.

This design is particularly suitable for retrofits and applications where the existing infrastructure is to continue to be used.
